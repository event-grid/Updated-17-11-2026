## 1. How to read this catalogue

**Source text is verbatim**, including its spelling and punctuation. Where this document needs to analyse a term, the analysis is in a separate column or section and does not replace the source term.

"Not specified in source" means the document is silent. It does not mean "none".

The reference IDs (`C01`, `C01.S05`) are proposed for traceability only. They are not source content.

### Mapping the requested hierarchy to the source

The source has only three labelled levels: **Main Services**, **Sub Services** and **Sub Types**. The other levels below are a classification of unlabelled source text.

| Requested level | How it was derived | Labelled in source? |
|---|---|---|
| Main event category | Items under "Main Services:" (p.1) | Yes, as "Main Services" |
| Event type | Items after "Sub Types:" (Weddings and Meetups only) | Yes, as "Sub Types" |
| Subcategory | Numbered items that divide a category rather than name a bookable service (Photography, Food, Event Managers, Corporate) | No |
| Service | Numbered items under a "Sub Services" heading that name something to be provided | Heading only |
| Service option / attribute | Text after a dash or colon on a service line (A-04) | No |
| Rental item | Only items the source marks `[Rental]` | Yes, once |
| Venue type | Named kinds of place in venue-related lines | No |
| Food type | Named kinds of food on food-related lines | No |
