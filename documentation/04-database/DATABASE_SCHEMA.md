# EVNTGRID — Database Schema (Proposed)

| | |
|---|---|
| **Database** | One PostgreSQL database on AWS RDS, one schema per module |
| **Status** | Proposed entity design for owner review. **This is not SQL, and no migration has been written.** |
| **Relationships** | Diagrams and cardinality are in `ENTITY_RELATIONSHIPS.md` |

## 1. Conventions

| Topic | Convention |
|---|---|
| Names | `snake_case`; singular table names |
| Primary keys | `id`, UUIDv7, generated by the application (ADR-012), unless stated |
| Timestamps | `created_at`, `updated_at` as `timestamptz` in UTC |
| Calendar dates | `date`, with no time zone, for event dates |
| Money | `*_minor` as `bigint`, with `currency` (ADR-013) |
| Status | `text` with a CHECK constraint (ADR-014). Values marked *provisional* are placeholders |
| Optimistic locking | `version` integer on mutable commercial records |
| Foreign keys | `ON DELETE RESTRICT` unless stated. Cross-schema FKs only to stable anchors |
| Provider-owned rows | Carry `provider_id`, protected by composite FKs where linked (ADR-015) |
| Soft delete | Not assumed; business records aren't hard-deleted while retention is open (U-16) |
| JSON | Only for immutable snapshots and external payloads |

## 3. identity

#### identity.user_account

| Aspect | Detail |
|---|---|
| Purpose | One person's central login identity |
| Primary key | `id` |
| Important fields | `phone_e164`, `email_normalized`, `display_name`, `status`, `last_sign_in_at`, `created_at`, `updated_at`, `version` |
| Relationships | One to many `user_role`, `user_credential`; one to zero-or-one `customer`; one to many `provider_member` |
| Constraints | At least one of phone or email; `status` CHECK (*provisional*) |
| Important indexes | Partial unique on `phone_e164` where present; partial unique on `email_normalized` where present |

**Unresolved:** identifiers required by sign-in method (U-01, U-02).

#### identity.role

| Aspect | Detail |
|---|---|

| Primary key | `code` (text) |
| Important fields | `code`, `description` |
| Relationships | One to many `user_role` |
| Constraints | Seeded with CUSTOMER, PROVIDER, ADMINISTRATOR. Visitor is the absence of a session and isn't stored (CD-17) |
| Important indexes | Primary key only |

#### identity.user_role

| Aspect | Detail |
